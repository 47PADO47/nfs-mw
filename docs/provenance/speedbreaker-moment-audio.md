# Speedbreaker moment audio provenance

Behavior was specified from the matched PC original's message recipient,
moment-stream controller, NIS stream selection and SPCH sample selector. The
CC0 `dbalatoni13/nfsmw` reference supplies names and corroborating structure;
the existing NOTICE credits that reference. Installed `aud_moment_strm`,
NISAudio index and PCM remain read from the user's game at runtime.

Static analysis establishes independent moment/common controllers and sample
selection. It does not establish full gameplay PCM or native DSP parity.
No original code, recordings, decompiler text or executable addresses are
included in the implementation.
