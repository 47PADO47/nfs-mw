The matched PC original's stream setter, platform callback, filter allocation,
coefficient builder and sample processor establish this behavior. An isolated
unchanged-instruction replay validates synthetic input and lifecycle vectors;
it does not observe gameplay audio. This processor is the same first-order
form already documented in `fxedit-processor.md`. The CC0 reference credited
in NOTICE corroborates the public setter API.

processor. Original binaries, extracted PCM, disassembly and private replay
