# World texture scrolling provenance

- The installed PC track supplies texture metadata and the campus fountain
  mesh-to-texture relationship. No game data is distributed here.
- The PC retail executable's texture setup and scrolling helpers establish
  signed field interpretation, fixed-point divisors and time behavior.
- [dbalatoni13/nfsmw](https://github.com/dbalatoni13/nfsmw), CC0-1.0,
  `Ecstasy/Texture.hpp` and `Texture.cpp`, independently describe the record
  and scrolling modes. No game code is copied.
- The final rendered fountain has not yet been compared against retail.
