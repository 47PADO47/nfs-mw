- [dbalatoni13/nfsmw](https://github.com/dbalatoni13/nfsmw), CC0-1.0:
  `Ecstasy/EmitterSystem.h` for the library and trigger layouts, and
  `Ecstasy/EmitterSystem.cpp` for library loading and world-effect servicing.
