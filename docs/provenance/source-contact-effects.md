# Collision effect provenance

The implementation follows [source-contact-effects](../specs/source-contact-effects.md),
written before code changes. Reference-only sources are the reconstructed
`Physics/Behaviors/Effects.cpp`, `Sim/Common/SimEffect.cpp` and
`World/WorldConn.cpp` in `dbalatoni13/nfsmw`. No source code was copied.

The matching local PC executable identity was checked before bounded inspection
of effect lookup, hit/scrape gates, per-owner callback routing and persistent
world-effect emission. Prior verified one-shot world-effect analysis establishes
the wrapper curve, visual cull boundary, owner inheritance and normal frame.
Raw binary details and captured events remain private.

Fresh passive original-game records independently observe posts, signs, wood,
glass, cables and vehicles accepting their own hit effects, including vehicle
impact debris. These records establish that the former audio-only prop callback
and player-only world-spark paths omitted real visual producers. Acceptance is
distinct from eventual emitter creation and particle support.

Installed data supplies every linkage, threshold, effect group, visual distance,
inheritance multiplier, particle texture and emitter profile. The implementation
reuses the existing independently reconstructed PC particle and emitter pipeline.
It does not infer visual profiles from selected sound IDs or generic prop names.

A further exact PC instruction comparison confirms the second-owner detached
callback preserves the shared pair normal, while the base callback reverses it.
The one-shot world-matrix conversion changes both bases, preserving identity;
merely swizzling its output columns would reflect particle coordinates. Bounded
installed tests cover real post world/object effects and cop/taxi impact groups,
plus persistent scrape expiry and native shared-layer delivery. Test outcomes
must be recorded separately; fixture existence does not establish a pass.
