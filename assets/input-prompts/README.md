# Bundled controller prompts

Kenney **Input Prompts 1.5A**, Xbox Series Double PNG subset.
Source: https://kenney.nl/assets/input-prompts

Attribution is optional; this project credits Kenney.

`kenney-xbox.png` packs 27 icons into eight columns of 128-pixel cells, with four-pixel padding.
Each source image is centred and fitted to 120 pixels, preserving aspect ratio. Remaining cells are transparent.
Order: A, B, X, Y, LB, RB, LT, RT, Menu, View, LS, RS, D-pad up/down/left/right,
left-stick up/down/left/right, right-stick up/down/left/right, D-pad horizontal/vertical, controller.
The icons are embedded in the executable and require no modded game installation.
Only these independently licensed assets are allowed by the repository's media leak check.
