# Bundled Discord mark

A white Discord logo mark for the Discord Rich Presence category icon.
Source: https://simpleicons.org (Simple Icons, `discord` glyph, SVG at https://cdn.simpleicons.org/discord).
License of the icon artwork: **CC0 1.0 Universal**, https://creativecommons.org/publicdomain/zero/1.0/
The Discord name and logo are trademarks of Discord Inc.; they appear here only to label the Discord settings.
This project is not affiliated with or endorsed by Discord.

`discord.png` is the SVG rasterised to 128x128 RGBA (white fill, transparent background) with resvg.
It is embedded in the executable and requires no game installation.
